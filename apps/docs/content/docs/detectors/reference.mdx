| ID | Label | Category | Regions | Description |

| `nin-ng` | NIN (NG) | gov-id | NG | Nigerian National ID Numbers |

| `nhs-gb` | NHS (GB) | gov-id | GB | UK NHS numbers |
| `nino-gb` | NINO (GB) | gov-id | GB | UK National Insurance Numbers |
| `ip-address` | IP Address | network | — | IPv4 and IPv6 addresses |
| `mac-address` | MAC Address | network | — | Hardware MAC addresses |
| `secret-key` | Secret / API Key | secret | — | API keys, tokens, passwords |
